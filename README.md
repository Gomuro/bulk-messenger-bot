# Bulk Messenger Bot

Бот для масової розсилки повідомлень.

## Опис проекту

Цей проект призначений для створення бота, який дозволяє здійснювати масову розсилку повідомлень.

## Вимоги

- Python 3.x
- Залежності вказані в requirements.txt

## Встановлення

1. Клонуйте репозиторій:

```bash
git clone https://github.com/Gomuro/bulk-messenger-bot.git
```

2. Встановіть залежності:

```bash
pip install -r requirements.txt
```

## Використання

Інструкції щодо використання будуть додані пізніше.
